Janus

Live · leagueoflegends.polaris-ai.org

A grounded question-answering engine for League of Legends. Ask it anything about champions, items, matchups, or the current meta and it answers from real data, cites what it used, and tells you when it doesn’t know rather than guessing.

Janus is a retrieval-augmented generation system written from scratch rather than assembled from a framework. That choice is what makes the rest of it possible: routing and retrieval behaviour are fully under my control, and every stage of the pipeline can be measured on its own instead of disappearing behind an abstraction.

Three retrieval strategies run behind one router, each matched to the kind of truth it serves: a version-pinned corpus for game mechanics, typed SQL tables for exact numbers, and a sanctioned live API for statistics that change daily. The generator is only allowed to speak from what retrieval found.

Python · FastAPI · Postgres + pgvector · React · Docker · Caddy · MCP
